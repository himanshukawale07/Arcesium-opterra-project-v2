# User Stories and Acceptance Criteria\n\n1. As a Reference Data Analyst, search securities by name, ticker or identifier; results show canonical ID, asset class and cross-reference identifiers.\n2. As a Pricing Analyst, compare vendor prices; vendor, value, currency, timestamp and priority are visible.\n3. As a Pricing Analyst, exclude stale observations; user sets maximum age and receives a warning if none qualify.\n4. As a Data Operations Analyst, run quality checks; each rule shows dataset, failures, severity and result.\n5. As an Integration Analyst, upload a CSV for schema preview; row count, columns and sample appear without persistence.\n6. As a Data Governance Analyst, generate a reusable report; select template/audience and download Markdown plus CSV detail.\n7. As a data consumer, export a selected mastered dataset as CSV.
